# Formommy

A mobile-first Russian A1 learning app for an English-speaking beginner.

## Product goal
Build a practical, friendly Russian-learning experience focused on short daily lessons, Cyrillic, listening, vocabulary review, and guided conversation.

## Initial scope
- Mobile-first web app
- English interface
- Russian A1 course
- Lesson flow
- Vocabulary review
- Progress tracking
- Future AI tutor and role-play

## Development workflow
This repository is designed to be developed and managed from a phone using GitHub and cloud tooling.
